# 本地公告、新闻、政策解析复用契约

当前接入点为 `scripts/local_fund_incremental_pipeline.py`，只用于本地验证。独立
SQLite 库默认为 `.local-runs/document-parse-cache/parsed-documents.sqlite3`。未改
正式预测服务、定时任务或业务数据库，也没有云端或收费提供者回退。

## 哪些内容可以跨日复用

材料编号、来源原件摘要、正文摘要、完整性范围和解析契约共同识别一个版本。
同一版本的解析结果跨预测日期、基金仓位变化和模型名称变化复用，保留实际解析
模型与原始文件来源。恢复截断正文、原文修订或解析契约变化需要处理新版本。
标题相同不代表原件相同；不能按标题或单纯发布日期缓存。

缓存保存事项、原文引用、条件、阶段和解释。今日净值、行情、仓位关联和目标日
比较基准由本日快照重新组织；不得继承旧预测方向作为本日结论。综合输入由已有
事项归并和证据构建程序生成，继续按公司与具体事项区分，不按文件数量加权。

## 首次结果、准入与失败

`parse_attempt` 原子保存首次开始记录；`parse_result` 仅允许插入首次结果。两个
进程不能同时解析同一版本；首次响应、请求与失败还独占保存在实验文件中。

- `SOURCE_CHECKED`：原文身份、引句及已有独立规则通过，可复用；不等于全面
  语义验收或预测发布批准。
- `REJECTED`：已知人工错误、引句不支持、原文不完整或独立规则告警。保留但不
  当成可复用事实，也不自动重试来掩盖首次错误。
- `FAILED`：已收到但不完整、结构非法或准备失败，保留原始结果。
- `UNKNOWN` 或只有开始记录：传输结果未知或进程中断。禁止重发同一版本；
  当前批次不继续调用，先核对服务器与首次结果。

旧实验可以通过 `--import-archive` 迁入逐公告解析，原来的人工错题同时迁入。
导入不读旧 UP/DOWN 预测或综合解释，不把旧模型自评作为通过依据。读取缓存时
再次核对原文、结果哈希及独立规则；旧解析错误不会因落库而变成正确事实。
首次解析之后发现的新错误，追加到 `parse_review` 撤销复用，保留首次答案和哈希，
不覆盖原结果或自动重发模型。审查使用的输入截止时间同样参与历史回放过滤。

## 时间边界

来源实际取得时间、公开日期以及解析使用的输入截止时间都不得超过本轮截止。
历史回放不复用以更晚输入生成的缓存，不读取更晚修订的材料。解析执行时间与
资料截止时间分别保存，不能拿今天的行情补到旧事件解释中。

## 运行和验收

使用项目 `.venv/Scripts/python.exe`。不加 `--run` 只导入、查询缓存并形成综合输入；
全命中时不初始化 Ollama 客户端。加 `--run` 后只处理 `PENDING` 材料，默认每个
请求包含一份完整原文及已匹配的 PDF 表格结构；完整输入超本地请求预算则保留
失败，不截断。`--max-calls` 可限定本次新增调用数，后续运行只处理剩余材料。

输出 `cache-plan-before.json`、`parsed-documents.json`、`synthesis-input.json`、
`summary.json` 和代码/输入哈希清单。旧实验与当前新增运行分目录保留。

相关测试验证公告/新闻/政策跨日持久化复用、仅新增调用、版本变化、原文恢复、
已知错误隔离、未知首次不重发、历史截止、并发抢占、结果篡改与旧档幂等迁入。
真实验证另记录本机请求及后续缓存命中；单测通过不证明候选模型全面理解正确。
