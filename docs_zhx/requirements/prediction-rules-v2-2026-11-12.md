## 1. 问题与目标

第一版已经会检查来源、日期、引文和本人账号中的保存结果，但对不同周期主要是文字提醒。实际判断仍可能重复使用同一组事实，反证和改变条件也可能套用通用文字。第二版要说清“怎样从资料得到这个周期的方向”，不能把格式检查通过当作判断正确。

每份判断必须说明：发生了什么变化、与基金有什么关系、已知资料能代表多少组合、还有什么不知道、价格已经怎样反应、什么时候起作用、最强支持与反证、为什么这样取舍，以及什么情况会改变判断。已发生但尚未进入已公布净值的变化，与真正未来变化分开。

参考十一月十日评分简化的做法：先核实主要依据，详细资料可以继续补；不照搬评分的分数或权重。首次试验把多数缺项都当成关键缺口，确实过严，现已修正。

每个缺项都要分别说明，不能统一打成“不完整”：

| 情况 | 怎么处理 | 例子 |
|---|---|---|
| 已有主要依据，缺项只影响把握或精细程度 | 可以给有条件的倾向，同时保留限制和补查任务 | 已核实行业指数和主要成分，不必先拿到实时全部权重 |
| 缺少的当前事实可能改变主要方向 | 继续补查，补到前暂不判断 | 可转债主要持仓的有效赎回条款不明；境外估值日或汇率口径不明 |
| 依据已有，但未来仍可能变化 | 写清不利情形和改变条件，不因存在风险就一律拒绝 | 订单已经核实，但未来客户可能削减采购；不能冒称削减已经发生 |

“可能改变方向”要有现实依据，不能仅凭“什么都有可能”就停止。也不能将真正缺少的当前事实换个名字叫未来风险来绕过检查。每个保留缺项都写明影响和下一步，给出方向也继续补查。

不要求天天有新消息，不要求精确知道市场所有人的预期，不要求每天拿到实时全仓。持续经营、利息、政策执行或行业变化可以用，但要说明为什么还有效、怎样影响本周期、什么情况会中断。昨日上涨或下跌本身仍不能独自成为未来方向。

五日可以分析持续推动因素，不强求一条新公告；二十日可以用持续观察的经营或行业指标验证，不强求固定的公告日期。四个周期仍须分别说明作用时间，不能复制一个方向。

半年官方估值终点暂未确认时，可以单独保存“有条件展望”，先讨论经营、利率等长期因素；不能冒充已确认日期的正式半年预测，也不能计算到期成绩。来源本身不合格时，仍不能给方向。

名义半年日期和核实的结束估值日分别保存。本批基准2026年11月11日加六个自然月为2027年5月11日，这个名义日期不是空白；最终结束日还需按产品估值条款及官方交易日历确认。不能把行政调休表直接当作交易所日历。

最新实际情况见[修正和同样本复核记录](../implementation/prediction-rules-v2-balanced-2026-11-12.md)。下文的“终点未核实”限制针对正式日期预测，不妨碍另存有条件展望。原试验保留，不能将修正后的结果说成原来就已完成。

## 2. 目标及结论

- 一日：真实基准估值日至下一目标估值日；五日、二十日：基金适用估值交易日；半年：基准日起六个自然月。不能用普通工作日替代产品规则或官方日历。
- 第二版目标为含已核实分红、拆分的基金总回报，不包含个人成本和申赎费。旧一日原净值口径与旧多周期目标不改写；试验不得冒称已完成新旧正式核对迁移。
- 结论：偏上涨、偏下跌、基本持平、暂不判断。资料缺失、时间口径未核准等阻断单列，不伪装为已经审阅后的中性判断。
- 基本持平必须先规定多大涨跌算小幅变化，而且该范围要适合基金类型和周期。现有范围仅作历史对照；本轮没有验证新的范围，试验不能输出基本持平，也不能借用其他类型的范围。
- 不设置未经验证的固定权重、胜率、上涨概率或确定收益。把握保持低，效果为尚未验证。

## 3. 共同分析要求

1. 先确认本份额、主基金、目标基金、资产类型、策略和计价币种；分类以正式产品资料为准，名称只帮助找候选。同一基金可以同时需要多套检查，例如境外联接基金要检查底层资产、联接安排和汇率。
2. 只使用实际取得且公开时间符合资料截止的来源；区分新事实、旧事实的新变化、历史背景、计划和未经核实推测。
3. 每条采用的因素都要对应到真实事实和连续原文，说明与基金的关系、覆盖范围、作用时间及什么变化会推翻它。
4. 同一事件、转述、底层证券和指数对同次行情的反映按共同经济事件归组，不能按来源或正负条数加分。
5. 支持和反证分开查找，不能先选方向再套几句反证。同一事实可能有两种相反影响时，分别解释。
6. 必需检查可以得出缺口，不能要求分析者编造合格事实。缺项可能改变方向时暂不判断；辅助资料缺失不自动阻断。
7. 不从净值趋势、评级高低、经理名气、低估值或新闻数量单独推出方向。量价事实必须解释其代表范围与尚可作用的原因。
8. 不猜当前持仓、经理未来调仓、市场一致预期、未公开订单、未来政策结果或未知汇率对冲。

## 4. 四周期规则

| 周期 | 必须检查 | 形成方向的条件 | 暂不判断的典型原因 |
|---|---|---|---|
| 一日 | 新增信息、主要投向的相关市场、基准/已实现未入净值/未知未来三段、下一估值日事件 | 有本目标日作用的驱动、组合关联与可解释的延续/反转机制，且反证不主导 | 只有昨日行情；主要作用已实现；海外时间错位；次日重大结果未知；历史部分持仓不能代表组合 |
| 五日 | 五日内催化与节点、持续性、多日行业参与范围、经营价格关系、短期资金及兑现风险 | 推动因素在本窗口有可核查的继续作用路径，说明何时中断 | 只有题材；把一日结论延长；催化时点不明；重大二选一事件决定方向 |
| 二十日 | 经营变化、行业供需与成本、政策执行、验证节点、估值要求、组合代表性 | 事实到经营/资产再到价格和基金的路径明确，作用与本窗口匹配 | 只有长期故事；缺执行；作用在远期；旧数据不能代表；跨周期转向无解释 |
| 半年 | 收益来源持续性、经营质量、估值假设、行业周期、宏观风险、组合变化、验证节点 | 有主要/有利/不利三情形，主要情形有支持，结果不依赖多重乐观假设 | 缺关键长期资料；小幅合理假设变化即翻转；新策略无代表资料；只靠近期行情；产品终点未核实 |

观察窗口不等于预测窗口，不规定只准读最近几日；旧资料可以作为背景，但升级为本周期主驱动须说明当前有效性。

## 5. 不同基金分别补看什么

这里用到的几个词：ETF是可以在交易所买卖的基金；联接基金主要投资另一只目标基金；指数增强是在跟踪指数之外争取多一些收益。久期表示债券价格对利率变化有多敏感；信用利差表示投资人因多承担信用风险而要求的额外收益；转股溢价表示可转债价格比立即转成股票的价值高多少。下面仍以各基金自己的真实条款为准。

| 类型/叠加项 | 必须分析 |
|---|---|
| 宽基股票指数 | 指数结构、整体经营与估值、利率和市场广度；不得用少数热点代替指数 |
| 行业主题指数 | 行业供需、价格/成本、经营验证、政策适用对象、主要成分代表性 |
| 主动股票 | 最近披露组合与范围、风格、集中度、经营估值；不猜未来调仓 |
| 指数增强的额外检查 | 先分析基准，再看额外选股和偏离风险；不能预加未经验证的额外收益 |
| 联接基金的额外检查 | 继续查看目标基金实际买了什么，不把交易价格高于净值的部分当基金收益 |
| 利率债/纯债 | 利率曲线、久期敏感性、利息收入、融资及流动性，核对是否包含信用风险 |
| 信用债 | 债券共性及偿债能力、信用利差、集中风险；利率下降不能抵消未知信用问题 |
| 可转债 | 对应股票、债券价值、转股溢价、信用，以及赎回、回售和转股条件及日期 |
| 混合/固收加 | 主要资产分别分析再合并，披露比例与未知部分单列，不从名称或基准推出现仓 |
| 黄金 | 利率/美元及人民币换算、风险需求、资金与价格、底层现货/期货/基金结构；不套企业利润逻辑 |
| 其他商品 | 实际标的供需、库存、产品期货结构及换月；商品与商品股票分开 |
| 境外投资的额外检查 | 当地资产、汇率、是否采取措施抵消汇率影响、时区及适用估值日；已发生部分不冒充未来预测 |
| 基金中基金 | 这种基金主要买其他基金；要继续查看主要底层、资产分配、是否重复投资相同资产、费用及未知部分 |
| 基础设施基金 | 运营现金流、分配来源、负债、利率与市场价格，不将分配率当总回报 |
| 货币基金 | 收益水平变化、再投资、流动性信用；独立目标不套股票方向 |

## 6. 正反因素怎样取舍，什么时候先不判断

不按条数投票。先排除不适用的依据，再比较影响多少主要资产、能否在这个周期起作用、已经发生还是尚待兑现、价格怎样反应，以及还不知道什么。必须说明最强支持、最强反证及为什么一方更重要。重大风险也须证明与基金有关，不能仅凭标题就否定全部判断。看涨依据不足不等于看跌。

暂不判断的原因至少区分：必要资料缺失、资料不能代表主要组合、正反难分、作用时间不明、价格反映不明、重大事件待定、基金日期或计算方式未核实。每项写清缺什么、补到什么以后再判断。“尚未阅读”是工作还没做，不能算分析后决定先不判断。

不同周期方向可相反，但必须解释短期压力、中长期支持及转变条件；不能只写“短期调整长期看好”。

- 三份方案、独立V2政策与结构化审阅校验、命令行试验入口、边界回归、当前持仓类型样本与逐基金四周期试验记录。
- 先在独立试验通道实施V2：不修改V1政策文件、既有预测/答案、每日调度、订单、评分或数据库结构。试验结果单独存D盘，明确不是本人页面正式预测。
- 从正式本人正份额持仓动态读取，按资产类别及联接/增强/境外叠加项选代表。没有持仓的类型不借其他基金冒充覆盖；资料缺失的代表照实记录，不为凑成功率换样本。
- 每份试验保存所用资料的校验值、真实截至时间、实际分析时间、规则、分析和结果，保存后重新打开核对。未到期的成绩不提前给出。用旧资料重新分析，不算新的事前预测。
- 程序验证来源与结构，不宣称机器已证明因果解释或预测有效。试验后再依据结果继续正式通道接入；总回报目标、持平范围、Java本人归档与前端消费的迁移须另列实测完成情况，不以本地试验代替。
