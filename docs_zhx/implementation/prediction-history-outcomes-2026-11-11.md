# 预测历史到期核对修复（2026-11-11）

用户要求把一日到期核对接入每日任务，补齐已到期历史结果，并区分尚未到期、缺数据、尚未核对和没有预测。

## 原因与修复

- 一日答案原先只由单独的Java核对定时器保存，统一开发入口关闭了该定时器。每日资料任务中的历史核对子任务仅覆盖五日、二十日和半年，造成一日漏核对。
- 综合分析答案读取函数遗留固定基金`002112`，其他基金可能误用该基金净值。现按原预测的真实基金代码读取、保存来源身份，并由Java同时核对答案和两个净值来源的基金代码。
- 新增V31数据库迁移：旧预测和答案不修改、不删除；来源不符的综合分析旧答案排除出有效结果视图。历史页面、当前结果及统计统一使用有效结果；“首次答案”是首份有效答案，不能被被排除的旧版本占据。
- 每日续办在资料终态后调用仅本人当前模拟正份额持仓的一日核对入口。每页50条、最多100页，固定本轮北京时间日期，只核对此前日期的原预测，不补造新预测、不请求缺失资料补拉、不启用训练或学习回执。
- 最近核对状态与不可变答案分开保存。缺数据与核对失败分别记录；保存答案后实际读回，分页结束再次核对本人范围与数据库完成数。每日检查单独核对一日回执和Java实际状态，缺项不报成功。
- 一次性补核本人全部原档案使用独立入口、独立范围和独立回执。每日任务不能采用该范围，也不能覆盖当前持仓回执。
- 页面有答案时展示实际涨跌和方向是否相符；没有答案时分别显示“尚未到期”“缺少数据”“尚未核对”或“核对未完成”。未核对不再冒充净值“待公布”。到期判断以目标日期结束为界，与每日00:30处理前一日的规则一致。
- 每个可见页面的多周期记录按日期一次读齐，缺少周期经完整查询后显示“没有预测”。请求失败或跨页尚未读齐时不声称没有预测；补读不改变原翻页游标。
