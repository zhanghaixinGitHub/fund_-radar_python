- 新增独立契约`QDII_CNY_VN_CONTRACT_SESSION_V1`，在`vietnam_valuation_contract.py`复核本人基金招募说明书、报告、估值日/收盘/汇率原句和官方年度日历。没有仅向原美国、香港、日本分支增加一个VN标志。

- `normalize_dnse_history`核对实际DNSE自身域、证券请求、1D周期、原始响应SHA256和越南当地日期。它只归一日期与原始数值，不从价格大小猜单位。
- 原文、当前行、前一已核交易日、证券及涨跌幅一起绑定。涨跌幅须与真实两日收盘相符，不能填写任意有限百分比；不能借同文档中另一证券的行。
- 千盾换算须有同提供方的真实单位说明，支持原文`đồng/cp`、`Giá hiển thị x 1.000 = Giá thực tế`，不将VNDIRECT单位说明替DNSE背书，也不擅自把21.05当21.05越南盾。
- 官方美元兑人民币与合同指定彭博伦敦16时汇率分别复核，伦敦时间按实际时区处理夏令时。USD/VND表示每美元多少越南盾，人民币每越南盾使用美元兑人民币除以该值；逆向报价明确标为VND/USD时才使用乘法，不按数字大小猜方向。
- 普通即期、代理汇率、错日/错时记录、零售银行牌价不冒充合同指定汇率。替代分支必须有本基金当日托管方实际启用并提供估值用汇率的证据；网络超时不等于托管方已启用替代。

- `time_context`、第二版基准检查、旧版分析/导入及第二版方向校验分别保留阻断。即使手填基准布尔值为真，缺指定汇率或真实本基金净值仍不能发布方向。旧版模型也不会为这些缺项先调用付费解析。
