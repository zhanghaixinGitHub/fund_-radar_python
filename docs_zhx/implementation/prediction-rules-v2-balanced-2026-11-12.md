## 参考了哪次评分修改

已经查看十一月十日的评分简化需求、实施记录，以及`fund_rating_evidence_preview.py`。那次将长期业绩、集中度、策略匹配、公开赎回条件等主要依据与更细的资料分开；可以用可靠的等效来源，缺项仍继续补。不能因为详细资料不全，就让大多数基金完全没有分数。

本次参考这个处理方式，但不复制评分权重。评分是在评价已有情况；预测还要解释为什么未来这个周期可能受影响，不能把基金评分高直接变成看涨。

## 改了什么，哪些边界保留

| 原来过严的地方 | 现在怎么做 | 仍不能放松的地方 |
|---|---|---|
| 未核实项多数统一当作会改变方向 | 每项分别写影响原因和补查任务；只降低把握的缺项可以保留 | 当前未知确实可能改变主要方向时，暂不判断 |
| 历史背景很难成为主要依据 | 经营、政策执行、行业变化可以说明持续作用，并引用实际读过的资料 | 昨日涨跌、基金名称或经理展望，不能单独推出未来收益 |
| 主要依据很依赖全面仓位和明显新事件 | 可以用正式投向、指数结构、代表性披露，说明范围与限制 | 几只小仓位个股不能冒充全基金，比较基准不能冒充实际仓位 |
| 未来存在风险也容易被判成无法判断 | 当前资料缺口和未来风险分开。未来风险写不利情形、观察点和改变条件 | 真正缺少当前事实，不能改名为未来风险绕过 |
| 五日、二十日过于依赖单独事件日期 | 持续驱动也可以，不强求一条新公告；说明本周期如何观察和中断 | 不能把远期故事机械塞进短期窗口 |
| 半年终点未齐，连趋势讨论也被卡住 | 另存“有条件展望”，继续分析三种情形 | 不伪造官方日历，不冒充到期日已核实的正式预测，不计算到期成绩 |

已解决的项目、保留限制的项目和关键缺口分别保存。给出方向也不取消补查任务。规则没有规定必须多少比例的基金给出涨跌结论。

## 不同类型怎样放松，怎样继续核实

| 类型 | 可以先用什么 | 哪些不能猜 |
|---|---|---|
| 宽基、行业指数及联接 | 正式跟踪关系、主要成分、行业或指数整体资料；联接继续看目标基金 | 少量热点不能代表宽基；目标基金交易价格不能直接替代基金净值 |
| 主动股票、量化及混合 | 最近披露的主要资产、集中度和风格；明确披露日期 | 不能假设今天仓位完全未变，也不能无证据假设已经彻底换仓 |
| 指数增强 | 基准先分析，额外选股风险单列 | 不预加未知的超额收益 |
| 政府债、信用债 | 披露久期范围、主要信用和利率资料，不要求每笔实时权重 | 旧利率不能当基准日利率，未知信用风险不能用利息收入盖过去 |
| 可转债 | 优先核主要持仓、正股和有效条款，小仓位缺项可列限制 | 主要转股溢价、有效赎回等会改变价格判断的内容仍要核实 |
| 黄金及商品 | 实际底层结构及代表性供需、价格、利率资料 | 不将旧金价当当前，不给人民币黄金机械再叠一遍汇率收益 |
| 境外基金 | 当地资产、计价与已核实的对冲安排 | 时区、估值日、汇率口径和资料截止不能错用 |
| 其他类型 | 按需求中的本类型主要收益来源分析 | 货币、基金中基金、基础设施及其他商品未在本轮实际样本中验证，不宣称已验证 |

## 实际补读了什么

复核使用原来9只基金的同一批夜间资料，9份原来源校验值不变。扩大了实际阅读范围，并非重新采集全市场资料。范围记录在试验目录的`reviewed-readings.json`；候选选段文件`supplemental-readings.json`不代表全部读完。

- **002112，德邦鑫星价值灵活配置混合C：**补读三季报资产和前十大表。九月底股票占总资产91.14%，现金及结算备付金7.80%；前十大股票占净资产合计73.17%。这些比例分母不同，不能混加。主要科技投向已有较强代表性，不能再笼统说“只知道几只科技股，所以完全不能分析”。补读多家公司经营后，增长支持与现金回收偏弱、部分单季利润下降并存。仍缺增长与当前价格要求的比较，不能直接推出基金未来上涨。
- **001632，天弘食品饮料ETF联接C：**补读两层持仓。联接基金九月底投资目标基金占总资产90.47%，直接股票占4.23%；目标基金前十大占其净资产54.24%。不能把联接基金少量直接股票当全部投向。多家主要公司单季承压，但累计表现、现金回收并非全部转差，不能只挑负面数据得出看跌。
- **013330，富国中证银行指数C：**补读主要银行财务和组合表。前十大银行合计占净资产61.03%。主要银行收入利润增长与部分利息收入、利润偏弱并存，仍需比较息差、坏账和估值；不能套工业企业现金流标准。
- **公告核实：**读到天弘停牌股票估值处理、德邦比较基准修改、富国销售渠道终止公告的相应段落。基金公司旗下公告不等于本基金一定受影响；比较基准修改不等于已调仓；渠道变更不直接推出净值方向。本轮没有据此增加涨跌因素。
- **日期核实：**一些名为`current-search`的旧记录实际只覆盖到十月中旬，不能当作十一月公告已查全的证明。夜间最新公告检查记录另有实际起止日期和来源清单；目录检查成功仍不等于本次逐篇读完。

日本样本继续保留原批准时间与后补资料不匹配的问题，不能把后来的事实放进较早截止。债券曲线、境内黄金现货的可用关键资料仍早于基准日；不把旧数据更名为最新。
