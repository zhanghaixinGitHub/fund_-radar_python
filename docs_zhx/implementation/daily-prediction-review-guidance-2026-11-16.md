# 每日四周期预测：基准、反证和资料缺口

本文件按用户2026-11-16“把这些预测规则接入每日任务，晚上自动生成结果”的要求生效。
沿用原北京时间每日00:30主执行和09:40独立检查，不增加第三项任务。
执行者是已有聊天定时任务中的分析代理；Python负责取材、冻结、严格校验与正式发布，
不会因单独运行一次命令就自动批准原文或推出方向。

## 每轮必须实际做完的事

1. 读根及子工程AGENTS、每日操作说明和本文件，检查新存储错误。动态读取绑定账号
   “我的持仓”的模拟正份额基金。没有固定29只名单，不从关注列表补入。
2. 运行原每日入口。先推进同一run_dir及资料作业，按缺项定向补真实净值、行情、
   原文、汇率和官方估值日规则。已有同版本解析可复用，缺必要原文时按规则读D盘原件。
   有界尝试其他可核来源；失败记录真实来源、时间、缺字段和恢复条件。
3. 评分仍按原授权执行。预测不等全部评分完成才开始，也不因一只基金等待而停止其他基金。
   对资料足够的基金立即完成本期sources、prepare、逐周期实际分析、evaluate、
   reviewed-trial-ref、原每日入口正式发布和逐项接口读回。逐基金分批处理以避免单对象过大，
   不裁剪来源全文。不得停在冻结成功、计划、草稿或旧结果检查。
4. 原目录目标已过期时，保留该次结果和真实取得时间；当前合法窗口通过正式入口另登记，
   不改旧目标、截止或原请求。下次日任务必须独立生成新一期，旧一期已审阅不能代替。

## 四周期独立取舍

| 周期 | 核心问题 |
| --- | --- |
| 一日 | 目标估值时段还有什么剩余传导；已实现涨跌不重复算未来收益。 |
| 五日 | 多日价格承接、已知事件与近端经营能否延续；不能拿一天走势乘五。 |
| 二十日 | 经营、现金、信用和政策如何在月内持续兑现；长期便宜不等于月内必涨。 |
| 半年 | 收入、回款、成本、融资、资产收入和资本配置的持续净作用。列三情景与失效条件。 |

先写基准及独立最强反证，再取舍净方向。可以给低把握方向，但须由真实证据支持，
不能默认现金恢复、股息到账、估值扩张、经理换仓或增强超额已经发生。
部分持仓或代表样本不自动阻断判断，也不能冒充全部实时资产。
申赎篮子与实际全仓、银行现金流与一般企业现金、现金余额与当期回款、
经营现金减资本支出与全部可分配现金必须分清。

## 把缺资料与未来风险分开

- 当前资料缺口（EVIDENCE_GAP）：说明缺什么，以及主要改变幅度还是可改变方向。
  若合理的未知仍可推翻净方向，保留暂不判断；不能为通过校验把UNKNOWN改成WEAKER。
- 未来反转风险（FUTURE_RISK）：如利率持续上升、需求恶化、未来回款低于基准，
  单列发生条件与撤回条件。未知未来本身不要求所有基金永远暂不判断。
- 已经披露的负现金、信用恶化和资金占用，是基准内真实反证，不是“缺文件”。
  低估值、历史股息或正现金不是自动看涨规则；不能只按正负公司数量投票。

例如纯利率债在有依据的平稳利率基准下，可由利息与费用关系支持低把握条件倾向；
精确久期未核主要限制幅度，而持续收益率上行是反转风险。
这只是分析方法，不是001021永久偏上，也不是其他债券基金复制方向的模板。
混合基金还要核股票风险与融资，可转债还要核转股、赎回、股债交叉暴露及真实期限。

## 时间与发布不能跳过

必须核真实基准净值和可见时间。境外投资基金未披露基准日净值时，可以参考前一个已核验沪深交易日的本份额正式净值，记录实际净值日期。行情和汇率继续按本期基准日核对，半年目标从实际净值日期算起。
收盘后窗口切换，不能把13日净值改成16日，
也不能把LOF场内价、盘中估值或代理汇率当正式净值。
未来官方日历未核时不推算普通工作日；半年可形成条件展望并保留名义终点，
不计为结束日期已核的预测。非半年不得用条件展望绕过日期与基准要求。
实际分析及发布晚于原窗口时如实标为补充/复盘，不倒填形成时刻或计事前准确率。

## 每轮结果和09:40检查

先报本轮新资料、正式评分和各周期新保存数，再单列沿用旧成果。
分别统计带日期方向、半年条件方向、已审阅暂不判断、资料等待、未审阅和研究草稿。
新增为0须明确写0及实际尝试，不能用116项历史记录核对通过替代。
09:40仅独立核对并反馈，不生成第二轮评分预测，不事后改写09:40事实。
