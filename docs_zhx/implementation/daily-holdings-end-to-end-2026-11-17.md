## 运行与继续

统一载入根`dev-env.ps1`。服务只用根`dev.ps1`检查、启停。先执行`app.commands.fund_daily_prediction`，同日继续原`--run-dir`、资料作业和目标窗口。入口先核当天新存储错误，错误或读取失败时停止写入。

入口会恢复未批准资料交接，实际补件，建立`monthly/YYYY-MM/*/request.json`，消费同目录经实际整理的`reviewed-bundle.json`。月评按最近结束月动态确定，不修改旧输入日期；编译后走正式register/update和查询读回。新期缺基准、净值、事项复核或类型资料的原因分别保留，技术待办不能报成外部无资料。

第二版预测现在由每日入口直接执行sources和prepare，返回`trial_directory`、`prepared_input`、`reviews_file`。逐基金实际阅读准备输入和相关原文，独立完成四周期实际分析，在返回的`reviews_file`写入严格审阅。输入准备、候选登记和草稿均不算完成。

实际审阅写完后，用同一个每日目录执行：

```powershell
. .\dev-env.ps1
Set-Location .\03-python
.\.venv\Scripts\python.exe -B -m app.commands.fund_daily_prediction --run-dir <原目录> --publish-prepared
```

此续办不重复采集已有候选，仍核当前材料、净值版本、本人持仓和原窗口。入口自动evaluate严格审阅，只有成功才写本周期发布凭据，再正式发布和读回。材料或晚到净值版本变化产生新准备输入；原快照和原审阅保留，不改时间凑新增。新期来源仍可补件或分析时，不能停在等待分析文件后结束；执行聊天必须继续实际阅读和撰写。
