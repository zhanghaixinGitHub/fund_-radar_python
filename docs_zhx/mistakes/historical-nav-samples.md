# 历史样本：未来数据不得决定过去特征的净值口径

适用场景：对完整历史序列生成逐日样本，优先累计净值、缺失时回退单位净值。

实际影响：初版对包含未来的全序列统一选择口径。未来累计净值缺失时，过去样本也回退单位净值，改变历史特征和哈希；另有标签未成熟时清空特征的问题。这会使训练时输入依赖未来数据状态。

已确认根因：口径选择在逐日循环外；特征构造与标签成熟判断共用不可用分支。

修复：每个起点只用当时已公布的特征窗口选择口径；先完成特征及哈希，再附加离线标签。标签必须沿用起点口径，缺值只使标签不可用，不能反向改写特征。特征版本改为`M3_STOCK_HISTORICAL_NAV_FEATURE_V2`。

预防：单测与HTTP测试覆盖未来缺值、未来收益反转、历史前缀与补齐标签后特征和哈希一致性。后续标准化、缺失值处理与特征选择同样须遵守时间边界。当前日期级预览尚不证明来源修订版本可回放。

## 公告滞后使预测起点过时

适用场景：来源的起点公告日晚于多条后续净值的公告日；包括季度末记录，也包括更新记录在所取后20条窗口之外的情况。

实际影响：旧规则只拒绝“第20条终点已经公告”，会把一段已经走过部分过程的旧起点标为SCORABLE。真实体检中，008888的2025-03-31起点记为4月22日公告，截止时后20条已有14条公布，旧实现仍接受。

已确认根因：样本资格判断缺少“起点是否为当时最新已公告净值”的检查。同步直接映射来源`ann_date`，内容变化时覆盖当前记录；来源字段为什么滞后、是否对应修订公告而非首次公告，尚未确认，不能推断为确定的源端错误。

处理：不改原始日期；仓储在同基金同来源下用相关EXISTS检查任意更晚且已有效公告的记录，再与公共构建器的序列检查合并。日期无效优先报告日期问题；其余旧起点在计算前返回`DATA_INSUFFICIENT / STALE_NAV_AT_CUTOFF`。样本筛选规则单独编号V2，指标公式/标签版本和正常特征哈希不变。

预防与后续：测试覆盖部分已知、第21条先公告、分页边界、来源/基金隔离、同日公告和长间隔正常情况；批量保留拒收项和原因计数。正式训练前仍须核实首次可得日期与历史修订保留方案，本检查不能替代这两项。
